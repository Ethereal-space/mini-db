# C-B01 Superblock 与数据库文件初始化

## 课程依据

G-P4、G-P6、G-P8；C-S2、C-S43；D-S7、D-S13、D-S15、D-S17

课程要求页式文件与重启持久化。page 0、固定 magic、具体字段偏移及格式版本是本项目统一选择，不能误称为 PPT 原样规定。

## 任务目标

建立可重复打开的单文件 mini.db。新文件恰含 page 0 与空 Catalog page 1，长度 8192 字节；已有文件只读取和校验，不擅自重新初始化。公开只读 next_table_id，供最终装配传给 CatalogService(initial_next_table_id)，使其与已登记最大表号一起计算下一个 ID，保留失败创建产生的空洞。

前置缺失时，只能在本成员授权目录内补齐最小必要部分；跨成员能力使用冻结 Protocol 和 tests 中的 Fake。

## 输入输出

输入是冻结 TableMeta、RID、行值、页号和临时数据库文件；输出是可重启恢复的页数据、StoredRow、缓存统计或结构化存储错误。不得解析 SQL 或绑定列名。

## 公共接口

`StoragePort` 与 `CatalogRepositoryPort`；核心页大小固定为 4096 字节，行地址使用 `RID`，扫描返回 `Iterator[StoredRow]`，缓存观测使用 `BufferStats`。

扩展不得直接改变冻结 AST、Bound AST、Plan 或 Protocol；跨层扩展统一使用 `ExtensionStatement`、`BoundExtension`、`ExtensionPlan(feature, version, payload, span)`。

## 实现步骤

1. 固定字段常量与struct格式，断言结构大小32字节，编写纯编码往返测试。
2. 实现新库初始化和已有文件打开分支，使用上下文管理关闭句柄。
3. 记录两次打开前后的文件字节与元数据，补充损坏文件拒绝测试。

## 预期代码结构解释

- Superblock.encode/decode：前32字节采用 <8sIIIiiI；magic=b'MINIDB01'@0、version=1@8、page_size=4096@12、page_count@16、free_head@20、catalog_head@24、next_table_id@28，其余4064字节为零。解码不修改文件。
- initialize/open：只对不存在或长度为0的明确新库初始化。初值page_count=2、free_head=-1、catalog_head=1、next_table_id=1；page1为空的table_id=0数据页。已有非空文件必须检查格式、长度及页号范围。
- validate：确认文件长度等于page_count×4096，版本受支持、页大小正确、目录首页合法。失败报告StorageFormatError及实际字段/文件偏移，span=None；不得遇到损坏就清空或覆盖原文件。
- 易错点：不能根据文件名存在就假定是合法数据库；也不能在打开异常后用wb模式重建文件。
- 整合范围：本任务无需其他成员；使用临时文件独测。最终integration负责把只读next_table_id注入B，不让B导入storage。

## 测试用例

1. `test_new_file_exact_layout`

   - 输入：不存在的临时路径，创建新库。
   - 必须断言：文件长度8192；前8字节MINIDB01；按指定格式解包六字段为1、4096、2、-1、1、1；page0尾部全零。

2. `test_catalog_page_bootstrap`

   - 输入：读取新库page1。
   - 必须断言：magic为MDPG、page_id=1、table_id=0、next=-1、slot_count=0、free_start=32、free_end=4096。

3. `test_reopen_preserves_bytes`

   - 输入：把合法next_table_id改为7并保存，再关闭、打开。
   - 必须断言：只读属性为7；打开前后文件字节完全相同，不重新分配Catalog页。

4. `test_reject_corrupt_header_without_write`

   - 输入：分别改坏magic、version、page_size及截短一个字节。
   - 必须断言：四种情况均抛StorageFormatError，含对应字段或偏移；文件哈希保持不变。

5. `test_id_initial_value_is_read_only`

   - 输入：合法目录最大ID为3，Superblock.next_table_id为7。
   - 必须断言：存储读出7且无setter；装配示例规定B取max(4,7)=7；无SQL位置的错误span为None。
