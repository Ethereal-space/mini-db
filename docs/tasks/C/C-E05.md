# C-E05 Clock 替换策略

## 课程依据

G-P4、G-P7；C-S35；D-S8、D-S15

课程要求常用缓存策略；Clock是在已完成LRU/FIFO后的可选比较实验。

## 预期代码结构解释

- on_access：页在环内只出现一次，设reference=1；新页加入固定位置。
- choose_victim：从hand开始，跳过pin，清引用位后继续；选中后hand指向后继。
- remove：移除页时修正hand，空池状态合法；不负责脏页写回，仍由BufferPool统一处理。
- 易错点：Clock不应复制一套写回逻辑；否则异常处理会与LRU/FIFO分叉。
- 整合范围：只在C内部切换策略，可独立完成；最终CLI若要选择Clock由小组扩展配置适配。
