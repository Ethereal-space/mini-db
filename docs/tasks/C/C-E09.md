# C-E09 B+ 树与 Index Manager

## 课程依据

C-S35；D-S9、D-S11、D-S12、D-S15、D-S17

PPT强调B+树与范围扫描原理，同时将复杂索引列为扩展；核心仍用SeqScan。

## 任务目标

实现页式B+树，叶子存(key,RID)并按key、page_id、slot_id排序；重复键保留多项。支持插入、分裂、根增长与闭区间扫描；删除先采用叶项逻辑删除，暂不实现合并。索引作为可重建辅助结构，不能替代表堆。

## 实现步骤

1. 冻结小扇出测试布局与节点不变量。
2. 实现叶与内部节点分裂。
3. 持久化根位置并对照排序数组验收。

## 预期代码结构解释

- find_leaf：采用复合分隔键(key,page_id,slot_id)，等值/范围下界以(key,-1,-1)搜索最左候选叶，避免重复key跨叶时漏左侧。索引节点均在专用页持久化。
- split：满叶分裂并连接next_leaf，向父传播分隔键；根满创建新根，更新扩展元数据。
- range_scan：定位下界叶后沿叶链过滤到上界，返回RID列表；重复键顺序确定。
- 易错点：维护表堆而不维护索引会返回错误RID；不能把独立树测试称为SQL已使用索引。
- 整合范围：C可独立建立并查询索引；SQL自动选索引还需B扩展计划、D索引算子和写入维护适配，集中另行整合。

   - 输入：小扇出插入乱序1至100。
   - 必须断言：根增长；全范围输出1至100递增，所有叶同深度。

   - 输入：小扇出下相同key=5插入足以跨3个叶页的不同RID。
   - 必须断言：等值查返回完整RID多重集合；删除一项并重启后只少该RID，无跨叶遗漏。

   - 必须断言：恰返回六键及正确RID。

   - 必须断言：其余重复键保留，重启后结果一致。
