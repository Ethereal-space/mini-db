# B-E07 GROUP BY 与聚合语义

## 课程依据

G-P4；C-S6、C-S35；D-S10

GROUP BY 与聚合属于课程可选扩展。本项目首版选择 COUNT(*)、SUM(INT)，不同时引入 HAVING、窗口函数或 NULL。

## 任务目标

绑定分组键与聚合参数，检查 SELECT 中每个非聚合列均出现在 GROUP BY。COUNT(*) 输出 INT 计数，SUM 仅接受 INT；禁止嵌套聚合。计划先扫描过滤再聚合，最后按 SELECT 顺序投影分组键与聚合结果槽位。

## 预期代码结构解释

- bind_group_keys：解析原行列索引，保留键顺序，建立分组结果索引映射。
- bind_aggregates：检查函数白名单、参数个数与类型，生成 function、arg_index、result_index 描述；嵌套聚合明确拒绝。
- build_aggregate：aggregate/v1 fields 写入 child、keys、aggregates、projection，投影使用聚合后的布局而非原行索引。
- 易错点：聚合后的行结构已经变化，继续使用原行 age index=2 会读错结果。
- 整合范围：B独立验收绑定和计划；全SQL需A-E05、B-E07、D-E04。NULL和其他聚合函数在后续版本定义，不更改v1空SUM错误语义。

## 测试用例

1. `test_group_projection_uses_aggregate_layout`

   - 输入：SELECT age,COUNT(*) GROUP BY age。
   - 必须断言：key 原 index=2，聚合结果布局 age 在 0、count 在 1。

2. `test_non_grouped_column_is_rejected`

   - 输入：SELECT name,COUNT(*) GROUP BY age。
   - 必须断言：拒绝 name 未分组，Span 指向 SELECT name。

3. `test_aggregate_types_and_nesting`

   - 输入：SUM(name)、SUM(COUNT(*))。
   - 必须断言：分别拒绝非 INT 参数和嵌套聚合，无计划返回。

4. `test_reference_group_counts_and_empty_input`

   - 输入：age 数据 20、20、21；另为空表无分组 COUNT。
   - 必须断言：按键比较结果为 {(20,2),(21,1)}；空表 COUNT 为 0，不能返回空结果代替。

5. `test_aggregate_v1_function_subset`

   - 输入：COUNT(age)、AVG(age)、MIN(age)；以及空输入全局SUM计划参考执行。
   - 必须断言：前三者语义拒绝未启用函数；空全局SUM为EMPTY_SUM_UNSUPPORTED，不伪造0。
