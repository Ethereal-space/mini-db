# B-B06 常量比较折叠、布尔化简与计划格式化

## 课程依据

G-P4、G-P7；C-S5、C-S33、C-S34、C-S41、C-S42；D-S10

指导书将优化列为可选，编译器 PPT 展示优化与可验证性。本方案主动把常量比较折叠和布尔恒等式化简列为两条基础规则；算术 10+8 留在 B-E03。

## 任务目标

自底向上优化 Filter 条件中的常量比较和 BOOL 运算，至少实现 TRUE AND p→p、FALSE OR p→p、NOT TRUE→FALSE，并记录规则名称、前后结构和触发次数。可删除恒真 Filter，恒假条件保留 Filter(FALSE)，避免另加核心节点。输出稳定、可读的原始与优化计划文本；优化前的 Plan 保持不变，再优化一次结构不再变化。

## 实现步骤

1. 建立常量比较规则与布尔规则的独立测试，明确哪些规则算作不同优化类别。
2. 实现不可变重建和稳定格式化，用原树快照证明输入未改；为重入调用测试幂等。
3. 用测试内独立参考求值器遍历固定行集比较前后谓词和结果，保存两份计划及各规则计数。

## 预期代码结构解释

- fold_constants(expr)：仅当比较两侧为同类型 BoundLiteral 且操作合法时求值，结果为 BOOL literal，Span 采用原表达式。不能执行用户函数或对未绑定 AST 做折叠。
- simplify_boolean(expr)：先递归子树，再匹配恒等式；只针对核心无 NULL 的 BOOL。重建受影响节点而非改写旧节点；Filter(TRUE) 返回原 child，Filter(FALSE) 仍保留用于空结果。
- optimize(plan)、format_plan(plan)：遍历所有表达式和子计划，记录可解释的规则命中；格式化按固定字段顺序，输出类型、列索引、算子和表名，不能包含不稳定的对象地址。
- 易错点：不能把打印两种格式当成两条优化；也不能只用优化器自己的计算函数验证其等价性。核心没有 NULL，是布尔恒等式成立的明确前提。
- 整合范围：单模块使用参考求值完成证据；集中整合由 D 真实执行同一数据上的原始与优化计划，比较结果行并在 Trace 展示两份树。

## 测试用例

1. `test_constant_comparison_folding`

   - 输入：Bound 条件 1=1、1<0、'a'!='b'。
   - 必须断言：分别生成 BOOL True、False、True；原 Span 保留，constant_comparison 计数精确为 1/例。

2. `test_two_rules_transform_demo_plan`

   - 输入：Project(Filter(1=1 AND age>=18,SeqScan))。
   - 必须断言：优化后为 Project(Filter(age>=18,SeqScan))；constant_comparison 和 boolean_simplify 各至少命中 1；原树仍含 AND。

3. `test_true_filter_removed_false_filter_kept`

   - 输入：分别为 Filter(1=1,Scan) 与 Filter(1=0,Scan)。
   - 必须断言：前者返回 Scan；后者为 Filter(Bool False,Scan)，不生成未冻结的 EmptyPlan。

4. `test_optimizer_equivalence_and_idempotence`

   - 输入：行集 (1,'Alice',20),(2,'Bob',17),(3,'Tom',22),(4,'张三',21)，谓词 1=1 AND age>=18 AND NOT(name='Tom')。
   - 必须断言：独立参考求值优化前后都选择 id=[1,4]；二次优化结构等于一次；原 Plan 完整保留。

5. `test_plan_format_is_stable_and_semantic_errors_survive`

   - 输入：同一 Plan 格式化两次；另编译 1=0 AND missing=1。
   - 必须断言：文本逐字相同且含 Project/Filter/SeqScan 和 age 索引 2；缺列仍在优化前报 Semantic 错误。

## 理解考试与小修改

- 讲解题：为什么必须先完成整个表达式的语义检查，再消去 FALSE AND p？
- 答案要点：p 可能引用不存在的列或包含非法类型；提前删除会错误接受无效 SQL。优化保持已合法程序的语义，不能改变语言的接受集合。
- 现场小修改：新增 p OR FALSE→p，先写规则命中、原树不变、前后逐行等价三类断言，再解释是否影响公共接口。
