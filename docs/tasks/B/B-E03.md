# B-E03 算术表达式类型检查与常量折叠

## 课程依据

G-P4；C-S6、C-S27、C-S33、C-S34、C-S35

C-S34 展示 age>10+8；核心只识别算术 Token，本任务补充绑定和常量优化，不自动增加 FLOAT 存储。

## 任务目标

绑定 INT 的 +、-、*，并把仅含常量的子树化简为 INT Literal；扩展首版 / 明确拒绝，避免未定义整数除法语义。每一步检查 INT32 溢出，保留原 Span。复现 age>10+8→age>18，并证明行结果一致。

## 预期代码结构解释

- bind_arithmetic：读 kind/fields/span JSON 节点，检查 op 与两侧 INT 类型，输出同版本 BoundExtension。
- fold_arithmetic：自底向上计算纯常量子树，每次检查范围；非纯常量子树保留结构，不读取行数据。
- validate_payload：feature=arithmetic、version=1，fields 必须包含 op、left、right；缺键和不支持的 / 给出明确错误。
- 易错点：Python 整数无固定上限，不代表 MiniDB INT 可以静默超出 32 位。
- 整合范围：独立完成 B 类型与优化；完整 SQL 需要 A-E07 和 D 对同版本算术 Bound 扩展的求值支持，不能仅凭 Token 可识别宣布完成。
