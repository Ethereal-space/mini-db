# B-B02 CREATE 与 INSERT 语义检查和列值重排

## 课程依据

G-P3、G-P5、G-P6；C-S24、C-S25、C-S28；D-S10、D-S17

课程要求检查重复对象、INSERT 列数、列序和类型。本项目核心 INSERT 只允许提供完整列集合，不支持缺省值或部分列插入。

## 任务目标

让 CREATE 检查表名、至少一列、重复列和合法存储类型；让 INSERT 查表并验证完整列集合、值数量、重复名和类型。INSERT 不写列名时按建表顺序解释；写列名时重排为同一顺序。INT 必须处于有符号 32 位范围，VARCHAR 按 UTF-8 字节计长且不超过 255。任何失败都在发号和写入前发生。

## 实现步骤

3. 生成绑定结果并断言值 tuple；记录所有失败路径没有 allocate/register/save 调用，补充中文字节长度案例。

## 预期代码结构解释

- analyze_create(stmt,catalog)：只查询是否重名，验证 columns 后生成 Bound CREATE 描述。列 ordinal 按声明顺序从 0 编号，禁止在此阶段生成 table_id、first_page_id 或调用 Repository。
- bind_insert_columns(stmt,table)：先构建显式列名到值位置的映射，拒绝重复和未知列；验证集合恰等于 schema。按 ColumnMeta.ordinal 产生 tuple 值，保证执行器只处理 schema 顺序。
- validate_literal(value,dtype,span)：精确区分 Python bool 与 int；检查 INT32 上下界与 UTF-8 字节长度，不做字符串转整数。报 Semantic 错误并保留问题值或列节点的 Span。
- 易错点：len('张三') 是字符数而非存储字节数；isinstance(True,int) 为真，必须排除。INSERT 映射不能把重复列覆盖后当成合法字典。
- 整合范围：本任务以 FakeCatalog 完成；A-B03 提供等价 AST，B-B05 把绑定结果放入 InsertPlan，D-B03 只执行已重排值。

## 测试用例

1. `test_create_validates_without_mutation`

   - 输入：编译 CREATE student(id INT,name VARCHAR)，随后尝试已有表名及重复列 id、ID。
   - 必须断言：合法绑定含两列 ordinal 0、1；错误含重名位置；所有情况下 allocate/register 计数均为 0。

2. `test_insert_reorders_explicit_columns`

   - 输入：student schema 为 id,name,age；INSERT 列为 age,id,name，值为 20,1,'张三'。
   - 必须断言：绑定值精确等于 (1,'张三',20)；table 元数据与 Catalog 相同；源 AST 不被修改。

3. `test_insert_without_columns_uses_schema_order`

   - 输入：INSERT 无列列表，值为 1,'Alice',20；再改成只有两个值。
   - 必须断言：前者得到 (1,'Alice',20)；后者 Semantic 错误指出期望 3 实得 2，Catalog 无写操作。

4. `test_insert_rejects_duplicate_unknown_and_missing_columns`

   - 输入：分别使用 id,id,age；id,score,age；id,name 两列及对应值。
   - 必须断言：分别报告重复列、未知列、缺少完整列集合；错误含有关 Span；不得悄悄补 NULL。

5. `test_literal_boundaries_and_utf8_length`

   - 输入：INT 测试 -2147483648、2147483647 及越界；VARCHAR 测试 85 个汉字和 86 个汉字；再给 INT 字符串 '1'。
   - 必须断言：边界整数与 255 字节字符串通过；越界、258 字节与隐式转换全部拒绝，错误精确指向值。

## 理解考试与小修改

- 讲解题：执行器为什么不能再按 INSERT 的显式列名自行重排一次？
- 答案要点：语义模块已经输出 schema 顺序，再按用户顺序解释会重复置换；绑定结果就是稳定执行契约。执行阶段仍可做防御性校验，但不能重新定义语义。
- 现场小修改：新增 INSERT 列名大小写混用测试，确保 AGE,Id,NaMe 得到相同 tuple；解释规范化和原始 Span 如何同时保留。
