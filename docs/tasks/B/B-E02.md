## 测试用例

1. `test_required_columns_include_predicate`

   - 输入：SELECT name WHERE age>=18，原列 id,name,age。
   - 必须断言：需求列为 (1,2)，不是只有 (1)。

2. `test_project_composition_preserves_duplicates`

   - 输入：内投影 (2,0,1)，外投影 (2,2,0)。
   - 必须断言：合并索引为 (1,1,2)，输出名称与外层一致。

3. `test_pruning_rebinds_every_index`

   - 输入：保留原列 (1,2)，谓词 age 的原 index=2。
   - 必须断言：映射 1→0、2→1；谓词新 index=1，投影 name 新 index=0。

4. `test_pruned_plan_matches_reference`

   - 输入：行 (1,'Alice',20),(2,'Bob',17)。
   - 必须断言：原版与扩展参考解释均输出 [('Alice',)]；删除路径明确禁用裁剪。
