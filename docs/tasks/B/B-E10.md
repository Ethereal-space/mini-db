# B-E10 表统计与简单代价估算

## 课程依据

G-P4；C-S35、C-S41；D-S9、D-S10

PPT 将统计、代价和索引扫描列为高级方向。本任务实现可解释估算模型，不承诺估计等于实测耗时。

## 任务目标

对 SeqScan、Filter、Project 估算扫描页数、输入行数、输出行数及抽象代价。项目模型规定扫描代价为页数，过滤和投影每输入行增加 0.01；未知谓词选择率默认 0.5，已知恒真/恒假为 1/0。显示假设，不以虚假毫秒包装估算。

## 前置任务

B-B05、B-E09；通过本模块 FakeStatisticsProvider 提供统计，不依赖真实存储统计。 扩展输入以公共v1字段表为准，个人快照只验证同一格式。

前置缺失时，只能在本成员授权目录内补齐最小必要部分；跨成员能力使用冻结 Protocol 和 tests 中的 Fake。

## 输入输出

输入是手工构造或前端产生的冻结 AST、Catalog 元数据与版本化扩展信封；输出是 Bound AST、Logical Plan、优化后 Plan 或结构化语义/计划错误。不得读写真实数据页。

## 公共接口

`CatalogPort`、`CatalogRepositoryPort` 与 `CompilerPort.compile/optimize`；输入为冻结 AST/扩展信封，输出为 Bound 节点、Plan 节点或版本化扩展信封。

扩展不得直接改变冻结 AST、Bound AST、Plan 或 Protocol；跨层扩展统一使用 `ExtensionStatement`、`BoundExtension`、`ExtensionPlan(feature, version, payload, span)`。

## 实现步骤

1. 冻结统计快照和单位，写手算期望。
2. 实现三类算子估算及缺失统计路径。
3. 加入估算和实际运行的对比说明模板，不宣称两者相等。

## 预期代码结构解释

- TableStats：保存 row_count、page_count 和统计版本；拒绝负值，缺统计标为 unknown，不能默认为空表。
- estimate：后序递归计算行数与代价；Filter 输出向下取整，代价基于输入行数，Project 保持行数。
- explain_cost：列出每个节点的假设、公式和结果；只读 Fake 或注入统计接口，不扫描真实表获取数字。
- 易错点：估算过滤后没有行不代表扫描成本为零，数据仍需读取并判断。
- 整合范围：B 独立完成模型与展示；真实统计来源需集中注入 C 或 D 的测量结果。索引计划选择另依赖 C-E09 和对应执行能力。

## 测试用例

1. `test_scan_cost_equals_pages`

   - 输入：row_count=1000、page_count=10。
   - 必须断言：Scan 估计行数 1000，代价 10。

2. `test_filter_and_project_formula`

   - 输入：上述 Scan 加默认 Filter 再 Project。
   - 必须断言：Filter 行数 500、累计代价 20；Project 行数 500、累计代价 25。

3. `test_constant_predicate_selectivity`

   - 输入：1000 行，分别过滤 TRUE 和 FALSE。
   - 必须断言：输出估计 1000 和 0，过滤代价仍计输入 1000 行。

4. `test_missing_and_invalid_statistics`

   - 输入：缺统计、row_count=-1、page_count=-2。
   - 必须断言：缺统计显式 unknown；负数拒绝，不伪装成 0 行 0 成本。
