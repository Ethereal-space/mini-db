# B-E08 FLOAT、NULL 与三值逻辑

## 课程依据

## 任务目标

## 测试用例

1. `test_numeric_promotion_is_explicit`

   - 输入：INT 1 与 FLOAT 1.5 比较；VARCHAR '1' 与 FLOAT 1.0。
   - 必须断言：前者生成显式数值提升；后者拒绝隐式字符串转换。

2. `test_three_valued_truth_table`

   - 输入：TRUE/FALSE/UNKNOWN 的全部二元组合及 NOT。
   - 必须断言：逐格符合快照；FALSE AND UNKNOWN=FALSE，TRUE OR UNKNOWN=TRUE，NOT UNKNOWN=UNKNOWN。

3. `test_nullable_equality_not_folded`

   - 输入：可空列 x 的 x=x。
   - 必须断言：保留比较，不化为 TRUE；x=NULL 时结果 UNKNOWN。

4. `test_where_accepts_only_true`

   - 输入：谓词参考值 TRUE、FALSE、UNKNOWN。
   - 必须断言：过滤保留标记分别为 True、False、False；不调用 bool(None) 代替规则。
