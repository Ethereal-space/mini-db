# D-B02 SeqScan Filter Project 算子

## 课程依据

G-P4、G-P8；C-S30至C-S32；D-S9、D-S10

执行Logical Plan中的三类查询算子，保留行到物理位置的联系。拉取式协议由本项目选定。

## 任务目标

实现open、next、close生命周期，next返回StoredRow或None。SeqScan调用storage.scan；Filter只保留谓词为True的行；Project按indices重排values且保留原RID。空表立即结束，close可重复调用。查询最外层输出列名由ProjectPlan.names决定。

## 预期代码结构解释

- SeqScanOperator：open创建迭代器，next只前进一次，耗尽转为None；close调用生成器close释放资源，不能把数据库读写放入构造函数。
- FilterOperator：循环拉取child直到命中或耗尽，不能递归跳过上千行导致栈溢出；异常也须沿finally关闭child。
- ProjectOperator：对同一StoredRow创建新的values tuple，rid原样传递；索引重复则结果列也重复。算子树由plan递归建造，不直接识别SELECT文本。
- 易错点：如果投影丢掉RID，后续需要定位记录的算子会失效；核心DELETE不挂Project节点。
- 整合范围：Storage Fake维护StoredRow列表和关闭日志；物理多页遍历由C负责。
