# D-B01 BoundExpression 求值器

## 课程依据

G-P4、G-P8；C-S27、C-S28；D-S10

将语义阶段已经检查的表达式转为每行布尔结果。BOOL仅用于内部表达式是本项目约定。

## 任务目标

实现 evaluate(expr, values)。Literal返回原值，BoundColumn按index取值，比较产生bool，AND、OR短路，NOT取反。INT支持六种比较；VARCHAR仅支持等于和不等于。WHERE条件必须产生真正的bool；Python中bool属于int的子类，不能据此混淆SQL类型。

## 预期代码结构解释

- evaluate：递归分派不可变节点；输入是Bound表达式和schema顺序的tuple，不接收SQL或原始列名。取列只用index，不临时查询Catalog。未知节点抛ExecutionError并保留span。
- evaluate_binary：先读取左侧；AND遇False、OR遇True立即返回，其他情况才求右侧。比较运算使用白名单映射，不调用eval。合法输入不发生隐式字符串转数字。
- evaluate_unary：只接受NOT和bool。错误路径区分无效节点、越界列、类型契约破坏；报出节点位置和原因，测试应暴露编程错误，不能统一吞掉异常返回False。
- 易错点：不要把字符串"False"转成True，也不要按列名反复线性检索。
- 整合范围：Fake只需手工Bound节点；全链路依赖B-B04，D的验收可以提前完成。
