# A-B02 数字、字符串、转义、运算符和注释

## 课程依据

G-P3、G-P5；C-S8、C-S9、C-S11、C-S12；D-S2、D-S17

材料列出整数、3.14、字符串转义、双字符运算符和两类注释。本任务完整识别这些 Token；FLOAT 列与算术执行不随 Lexer 自动启用。

## 任务目标

补齐 INTEGER、FLOAT、STRING、比较和算术符号、括号逗号分号。数字模式固定为数字串及可选的小数点后数字串，不含指数；负号独立成 Token。单引号字符串用两个相邻单引号表达一个单引号，允许字符串内换行并保留原值。支持 -- 行注释和不嵌套的 /* */ 注释，未闭合必须有定位错误。

## 预期代码结构解释

- scan_number()：扫描十进制数字及可选小数部分；INTEGER.value 为 Python int，FLOAT.value 为 float。INT32 范围由 B 检查；1.、1..2、12abc 作为非法数字片段拒绝，不能拆开蒙混通过。
- scan_string()：记住开引号位置，逐字符累积 value，双单引号追加一个单引号，闭引号结束；EOF 前未闭合时报起始位置。value 与 lexeme 分离，中文及换行不丢失。
- scan_operator_or_comment()：先识别注释和双字符运算符，再识别单字符。注释不输出 Token；== 和 <> 暂保留可识别种别，Parser 负责规范化。每个成功分支必须消费字符。
- 易错点：字符串中的 --、/* 不开启注释；注释中的单引号不启动字符串；两类状态不能混用。
- 整合范围：仅需要 Token 契约；解析器必须能接收本任务 Token 全集，并对不支持的语法给明确错误，不得让 Lexer 偷做执行。

## 测试用例

1. `test_a_b02_number_and_operator_tokens`

   - 输入：20 3.14 + - * / >= <= != == <>
   - 必须断言：前两值为 20、3.14；其后 9 个运算符各为单独 Token；负号不并入前后数字，最后一个 EOF。

2. `test_a_b02_string_escape`

   - 输入：'Tom''s book' '张三' ''
   - 必须断言：STRING.value 依次为 Tom's book、张三、空串；首项 lexeme 恰为原文含外引号与两个内引号。

3. `test_a_b02_comment_positions`

   - 输入：-- x
SELECT/*中
文*/name;
   - 必须断言：Token 为 SELECT、IDENTIFIER(name)、SEMICOLON、EOF；SELECT 起点 (5,2,1)，name 起点 (19,3,4)。

4. `test_a_b02_unterminated`

   - 输入：分别扫描 'abc 与 /*abc
   - 必须断言：都报 LexicalError，start=(0,1,1)，原因分别为字符串未闭合、块注释未闭合；不会陷入循环。

5. `test_a_b02_bad_number`

   - 输入：分别扫描 1.、1..2、12abc
   - 必须断言：三例均词法失败，错误起点为 (0,1,1)，诊断包含非法数字；不得输出 INTEGER 后静默截断。

## 理解考试与小修改

- 讲解题：为什么 -2147483648 应先产生 MINUS 和 INTEGER，而不是让 Lexer 直接判断 INT32 越界？
- 答案要点：无符号部分 2147483648 与负号组合后才是 INT32 最小值；范围属于语义规则，提前拒绝会错误拒绝合法负数。
- 现场小修改：新增只影响词法的指数数字模式 1e3，在独立练习中增加边界 1e、1e-3 并解释为何核心语义仍拒绝 FLOAT。
