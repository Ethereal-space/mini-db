# A-B04 SELECT 与 DELETE 的语句结构

## 课程依据

G-P3、G-P5、G-P6；C-S6、C-S15、C-S20；D-S17、D-S18、D-S19

材料要求 SELECT、DELETE 和可选 WHERE。本任务只建立语句骨架；WHERE 表达式调用 A-B05 的本地入口，查询和删除不在 Parser 执行。

## 任务目标

实现 SELECT *|列清单 FROM 单表 [WHERE expression] 和 DELETE FROM 单表 [WHERE expression]。SELECT 的 columns=None 表示星号，不使用字面列名 '*'；显式列清单保持顺序与重复项。DELETE 缺少 WHERE 表示删除全表，AST 的 where=None。核心拒绝别名、JOIN、ORDER BY、LIMIT 和投影算术，由扩展任务显式引入。

## 前置任务

## 实现步骤

1. 在文法中固定星号、显式列清单和可选 WHERE 的 AST 表示。
2. 先实现无条件 SELECT/DELETE，再调用本地表达式入口，不复制表达式解析代码。
3. 补充缺词、混用星号、额外后缀等负例，检查 Parser 消耗了完整语句。

## 预期代码结构解释

- parse_select()：先区分 STAR 与标识符列表，再消费 FROM 和单表名；调用 parse_where_optional 返回 Expr 或 None。结果是 SelectStmt，不直接生成 ProjectPlan。
- parse_delete()：固定消费 DELETE FROM 与表名，再解析可选 WHERE；不允许省略 FROM；返回 DeleteStmt，删除目标不存在仍留给 B 判断。
- parse_projection()：至少一个列标识符或唯一 STAR；SELECT *,id 拒绝，SELECT id,id 合法并保留顺序。遇不支持的后缀必须由语句结束检查报错，不能静默丢弃。
- 易错点：无 WHERE 的 DELETE 是语法合法的全表删除，不得擅自补一个 false 条件；本任务也不能把 AST 当执行指令调用存储。
- 整合范围：只使用 AST 契约，不需要其他实现。WHERE 单测可构造表达式 Token，完整 A 模块验收后才交给 B 绑定。

## 测试用例

1. `test_a_b04_select_star`

   - 输入：SELECT * FROM Student;
   - 必须断言：SelectStmt.table.name=='student'、columns=None、where=None；无Identifier('*')。

2. `test_a_b04_projection_order`

   - 输入：SELECT name,id,name FROM student;
   - 必须断言：tuple(x.name for x in columns)==('name','id','name')；所有项均为Identifier并保留span。

3. `test_a_b04_delete_optional_where`

   - 输入：DELETE FROM student; 以及 DELETE FROM student WHERE id=1;
   - 必须断言：第一棵 DeleteStmt.where=None；第二棵 where 是 BinaryExpr('=',Identifier(id),Literal(1))。

4. `test_a_b04_missing_from`

   - 输入：SELECT id student;
   - 必须断言：在 student 第 1 行第 11 列报 SyntaxError，期望 FROM，实际 IDENTIFIER；错误 Span 覆盖 student。

5. `test_a_b04_reject_extra_syntax`

   - 输入：SELECT *,id FROM t; 与 SELECT id FROM t ORDER BY id;
   - 必须断言：第一例在逗号拒绝混合投影；第二例拒绝未启用 ORDER 后缀；两例不得返回成功 AST 再忽略剩余 Token。
