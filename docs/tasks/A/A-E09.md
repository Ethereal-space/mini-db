# A-E09 FIRST、FOLLOW 与 LL(1) 分析工具

## 课程依据

C-S14、C-S17、C-S18、C-S19；G-P3；D-S18

材料讲解预测分析基础。本任务提供教学工具验证文法决策，不要求把已完成递归下降替换为表驱动 Parser。

## 任务目标

输入以产生式列表表达的文法，计算 nullable、FIRST、FOLLOW 与预测表并报告冲突。epsilon 用独立标记，不与普通终结符混淆；开始符 FOLLOW 含 EOF。输出稳定排序，冲突给出非终结符、lookahead 和竞争产生式，不谎称全部 SQL 文法天然 LL(1)。

## 前置任务

本地依赖 A-B06 的 grammar.md；算法本身可用小文法独立测试。 扩展输入以公共v1字段表为准，个人快照只验证同一格式。

前置缺失时，只能在本成员授权目录内补齐最小必要部分；跨成员能力使用冻结 Protocol 和 tests 中的 Fake。

## 实现步骤

1. 固定文法数据格式和 epsilon/EOF 符号。
2. 分别实现三个不动点算法，打印每轮集合便于教学。
3. 建立预测表并用有冲突文法验证诊断。

## 预期代码结构解释

- nullable/FIRST：从空集合反复传播直到不再变化；序列 FIRST 只在前项 nullable 时继续。
- FOLLOW：从开始符 EOF 初始化，按产生式后缀 FIRST 和父 FOLLOW 迭代传播。
- build_table：对 FIRST(右部) 填表，右部可空时按 FOLLOW 填表；已有不同产生式则记录冲突。
- 易错点：存在循环产生式时不能只递归调用 FIRST；必须用有限集合的不动点迭代终止。
- 整合范围：教学工具可独立交付，不影响数据库运行接口；只有另选表驱动 Parser 时才需要额外替换验证。

## 测试用例

1. `test_a_e09_nullable_first`

   - 输入：S→AB，A→a|ε，B→b
   - 必须断言：nullable={A}，FIRST(A)={a,ε}，FIRST(S)={a,b}。

2. `test_a_e09_follow`

   - 输入：同上，开始符 S
   - 必须断言：FOLLOW(S)={EOF}，FOLLOW(A)={b}，FOLLOW(B)={EOF}。

3. `test_a_e09_table`

   - 输入：同上预测表
   - 必须断言：M[S,a]与M[S,b]均指 S→AB；M[A,b]指 A→ε，无冲突。

4. `test_a_e09_conflict`

   - 输入：S→aA|aB，A→x，B→y
   - 必须断言：明确报告单元 M[S,a] 中两条产生式冲突，不能后写覆盖前写。
