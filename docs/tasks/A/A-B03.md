# A-B03 CREATE TABLE 与 INSERT 的递归下降解析

## 课程依据

## 任务目标

实现 CREATE TABLE name(column INT|VARCHAR,...) 与 INSERT INTO table[(column,...)] VALUES(literal,...)。列定义至少一项，插入值至少一项；支持完整显式列序和省略列清单。FLOAT Literal 可保留供 B 诊断，FLOAT 列类型仍在核心语法报不支持。负整数字面量合并 MINUS INTEGER；不能把一般算术偷偷当作字面量。

## 预期代码结构解释

- Parser(tokens) 的 peek、consume、expect：只维护 Token 下标；expect 返回匹配 Token 或抛 SyntaxError，错误含实际 kind、期望集合和当前 Span。EOF 下不得越界访问。
- parse_create_table()：消费固定关键字、表名和逗号分隔列定义，生成 CreateTableStmt；列顺序和重复列名原样保留给语义检查，节点 Span 从 CREATE 开始到右括号结束。
- parse_insert() 与 parse_literal()：保留 columns=None 与显式 tuple 的区别；Literal 保存原值和覆盖负号的 Span。对 INSERT 不发号、不分配页、不判断真实表是否存在。
- 易错点：Parser 不得为了让示例通过而查询内存表字典；不存在的表、重复列和 INT 越界都是 B 的诊断责任。
- 整合范围：不依赖 Fake；直接比对冻结 AST。向 B 提交原始语法顺序和完整 Span，让 B 完成 schema 检查与绑定。

## 测试用例

1. `test_a_b03_create_structure`

   - 输入：CREATE TABLE Student(id INT,name VARCHAR);
   - 必须断言：CreateTableStmt.name.name=='student'；columns[0].name.name=='id'、dtype_name=='INT'；columns[1].name.name=='name'、dtype_name=='VARCHAR'；Span到右括号结束。

2. `test_a_b03_insert_column_order`

   - 输入：INSERT INTO student(name,id) VALUES('张三',1);
   - 必须断言：tuple(x.name for x in InsertStmt.columns)==('name','id')；values依次Literal('张三')与Literal(1)；不重排。

3. `test_a_b03_literal_boundary`

   - 输入：INSERT INTO t VALUES(-2147483648,3.14);
   - 必须断言：columns=None；首值为整数 -2147483648 且 Span 包含负号；第二值为 FLOAT Literal，等待 B 明确拒绝核心类型。

4. `test_a_b03_missing_separator`

   - 输入：CREATE TABLE t(id INT name VARCHAR);
   - 必须断言：在 name 的第 1 行第 23 列报语法错误；期望集合包含逗号与右括号，不是 KeyError 或 IndexError。

5. `test_a_b03_semantic_boundary`

   - 输入：CREATE TABLE t(id INT,id VARCHAR);
   - 必须断言：解析成功且保留两项同名列；随后独立输入 CREATE TABLE t(); 必须语法失败并期望列标识符。
