# A-E07 加减乘除表达式

## 课程依据

C-S6、C-S9、C-S16、C-S17、C-S27、C-S33、C-S34；D-S10

算术是材料扩展，可用于复现 C-S34 的 10+8；核心负整数字面量不能替代完整算术文法。

## 任务目标

在比较与 primary 之间加入 additive、multiplicative、unary 层，支持 + - * / 和一元正负号。含算术的语句使用 arithmetic v1 的 {statement} 编码，不改核心 Expr 可执行范围。文法固定乘除高于加减、同级左结合，NOT 仍包住完整比较。

## 公共接口

`FrontendPort.parse(source: str) -> list[Statement]`；核心产物只使用冻结的 Token、AST、Span 与错误类型，扩展产物使用 `ExtensionStatement(feature, version, payload, span)`。

扩展不得直接改变冻结 AST、Bound AST、Plan 或 Protocol；跨层扩展统一使用 `ExtensionStatement`、`BoundExtension`、`ExtensionPlan(feature, version, payload, span)`。

## 实现步骤

1. 写 EBNF 和预期 AST，再插入新解析层。
2. 通过同级结合、括号、一元运算测试确定树形。
3. 将 C-S34 SQL 的算术节点编码输出并回归 NOT 优先级。

## 预期代码结构解释

- parse_additive：循环消费 +、-，形成左结合 BinaryExpr 编码，不采用直接左递归。
- parse_multiplicative/parse_unary：乘除循环，正负号递归；运算节点保留 Span，算术类型交给 B。
- 扩展探测：按构建节点判断是否含算术；SELECT * 的星号仍是投影标记，不能误判乘法。
- 易错点：Parser 只构树，不判断除零；除法结果类型、整数溢出和求值顺序要由扩展语义明确。
- 整合范围：完整算术需 B-E03 的绑定/折叠与 D 求值扩展；仅 A 验收不代表 SQL 能执行。

## 测试用例

1. `test_a_e07_precedence`

   - 输入：SELECT * FROM t WHERE age>10+2*4;
   - 必须断言：右侧为 +(10,*(2,4))，最外比较 >，不能提前计算为 18。

2. `test_a_e07_left_associative`

   - 输入：SELECT * FROM t WHERE id=8-3-1;
   - 必须断言：算术树为 -(-(8,3),1)，不是 -(8,-(3,1))。

3. `test_a_e07_unary_and_not`

   - 输入：SELECT * FROM t WHERE NOT id=-2*3;
   - 必须断言：NOT 包比较，比较右侧为 *(Unary(-,2),3)，不是对布尔值做乘法。

4. `test_a_e07_missing_rhs`

   - 输入：SELECT * FROM t WHERE id=1+;
   - 必须断言：分号处报缺算术操作数，保留真实 Span，不出现递归溢出。
